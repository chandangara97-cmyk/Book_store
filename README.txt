THE READING NOOK - multi-page website
Pages: index.html, library.html, reviews.html, story.html, contact.html
Shared: style.css (design), app.js (books, reviews, prices, payments)

1. Open app.js. Edit the block at the top: CONFIG (email, phone, WhatsApp, address, UPI ID, payment link),
   PRICES, OPTS (borrow/digital rates), BOOKS and REVIEWS (replace the sample ones with real ones).
2. Upload ALL files in this folder to any web hosting (keep them in the same folder) and open index.html.
3. Payments: UPI QR/links go straight to your UPI ID. Add a Razorpay/PayU payment link in CONFIG.payLink for cards.
   Orders are confirmed by the customer sending the order on WhatsApp; there is no server to verify payments.
